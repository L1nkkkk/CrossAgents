# V5 任务书：去掉「AI 味」，把 Claude / Codex 放进界面

> 前序：[V4](V4-GUI.md) · 参考：Codex 桌面版（openai.com/codex 上的产品图）、Claude Code 桌面版、Linear · 2026-10-22

## 1. 问题

界面能用，但一眼就是「AI 产品模板」：靛紫色主按钮和发光的焦点环、emoji 头像配粉彩圆底、到处是胶囊标签、12–16px 大圆角卡片、回复用衬线体。Claude 和 Codex 两家只以 `claude · haiku` 这样的文字出现，看不出谁是谁。

## 2. 方向

参考 Codex、Claude Code、Linear 这类工具型产品：界面退后，内容在前。

| 方面 | 之前 | 之后 |
|---|---|---|
| 颜色 | 暖灰 + 靛紫主色 | 中性石墨（暗）/ 纸白（亮）；主按钮用墨色（亮色下黑底白字，暗色下白底黑字）；颜色只表示含义：状态、diff、厂商 |
| 链接与焦点 | 靛紫 | 低饱和蓝（`--link`），焦点环 2px，不发光 |
| 厂商 | 文字 | Claude、Codex 各有标记：Claude 是陶土色的星芒，Codex 是墨色的 `>_` 方块。出现在侧栏、团队、会话顶栏、用量页、新建队友 |
| 头像 | emoji / 粉彩圆底 | 默认首字母；底色是低饱和的色相（只做区分）；已有的 emoji 头像去色显示在中性底上 |
| 形状 | 胶囊、12–16px 圆角 | 6px（标签）/ 8px（卡片、输入框）/ 12px（输入区）；去掉阴影光晕 |
| 字体 | 回复用衬线体 | 全部无衬线；数字用等宽数字；标题 600 字重、不放大 |
| 动效 | 呼吸、旋转 | 保留 ✻ 和进行中的呼吸点（用户喜欢的 Claude Code 痕迹），其他去掉 |

保留：侧栏的「节点与轨道」结构、agent 作为同事（名字、头衔、头像颜色、人设）、⎿ 这类字形。

## 3. 验收

- 亮色和暗色下：首页、会话（含工具步骤和 diff）、团队、用量页各截一张图，对比前后。
- `npm test`、`tsc` 通过。
