# M1 任务书：ACP 驱动、claude 插件、agent 会话

> 依据：[DESIGN.md](../DESIGN.md) §5、§6 · 状态：已完成（真实 Claude 联调待用户登录后进行） · 2026-10-21

## 1. 目标

hub 能真正启动一个 agent 进程（经 ACP），给它发消息、实时看到输出、中断、停止。

```
crossagents agent add alice --plugin claude --model haiku --role worker
crossagents agent start alice
crossagents send alice "写一个 hello world" --wait     # 打印输出直到本轮结束
crossagents attach alice                               # 交互：实时输出 + 从 stdin 发消息
crossagents agent stop alice
```

## 2. 设计决定

| 决定 | 原因 |
|---|---|
| **ACP 线上类型自己写最小子集**（`drivers::acp::wire`），不依赖 `agent-client-protocol` crate | SDK v3 是完整框架、v1/v2 schema 并存且构造器 API 变动频繁；我们只需要约 15 个类型，未知字段一律忽略，兼容性更好 |
| **通用 JSON-RPC 层**（`drivers::jsonrpc`，NDJSON over stdio） | ACP 与以后的 Codex app-server 驱动共用 |
| **`AgentPlugin` / `AgentSession` trait 放在 core** | 编排层只认识它们（DESIGN §6.1） |
| **暂不定义独立的 `Driver` trait** | 目前只有 ACP 一种驱动；插件直接组合 `AcpSession`。出现第二种驱动时再抽象 |
| **插件 = 启动命令 + 模型映射**：`crates/plugins`（claude、codex、registry） | 两家都走 ACP，插件很薄；启动命令可被 `config.toml` 的 `[plugins.<name>] command` 或 agent 的 `config.command` 覆盖 |
| **模型选择**：`session/new` 返回的 `configOptions` 中找 model 选项并 `session/set_config_option`；claude 额外设置 `ANTHROPIC_MODEL` 环境变量 | 两层保险 |
| **权限**：hub 是 ACP client，`session/request_permission` 按策略自动应答（默认 `bypass` 选 allow 选项）；若 agent 提供名字含 bypass 的 mode 则切换过去 | DESIGN §8：Worker 全部放行 |
| **输出事件合并**：文本增量按 ~150ms 或遇到其他事件时合并成一条 `agent.output` 事件入库 | 避免每个 token 一行记录 |
| **离线 agent 收到消息时自动启动** | 与 DESIGN §9「目标空闲则作为新一轮输入」一致 |
| **mock ACP agent**（`crates/mock-agent`） | 不依赖真实 LLM 与账号即可做端到端测试；M2 起还能按脚本调用 MCP 工具 |

## 3. 新增事件

`agent.turn_started`、`agent.output`（text / thought）、`agent.tool_call`、`agent.tool_call_updated`、
`agent.turn_completed`（stop_reason）、`agent.usage`、`agent.error`。

## 4. 新增 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/v1/agents/{key}/start` | 启动会话 |
| POST | `/v1/agents/{key}/stop` | 停止会话 |
| POST | `/v1/agents/{key}/cancel` | 中断当前轮 |
| POST | `/v1/agents/{key}/messages` | `{ "text" }` → 202 `{ "queued": bool }`；离线则自动启动 |
